1. Climbing Stairs

    Explanation: You are climbing a staircase. It takes n steps to reach the top. Each time you can either climb 1 step or 2 steps. Find how many distinct ways you can reach the top.

    Input: n = 4

    Output: 5

    ==================================================

    BRUTE-FORCE

    Idea: Try all possible ways of climbing stairs by choosing 1 step or 2 steps at every position and count all valid paths that reach exactly n.

    Steps:
    1. Start from step 0
    2. At each step, try jumping 1 step
    3. Also try jumping 2 steps
    4. Count all ways that reach step n exactly

    Time Complexity: O(2^n)

    Space Complexity: O(n)

    Why It Won't Work Efficiently?
    Because:
    - Recomputes same subproblems again and again
    - Exponential number of recursive calls
    - Very slow for large n

    ==================================================

    OPTIMAL

    Idea:
    This is a Fibonacci pattern problem. Number of ways to reach step i is sum of ways to reach (i-1) and (i-2).

    Steps:
    1. Initialize base cases for 1 and 2 steps
    2. Iterate from 3 to n
    3. At each step, add previous two results
    4. Return final value for n

    Python Code:

    class Solution:
        def climbStairs(self, n):

            if n <= 2:
                return n

            prev1 = 2
            prev2 = 1

            for i in range(3, n + 1):

                current = prev1 + prev2
                prev2 = prev1
                prev1 = current

            return prev1

    Time Complexity: O(n)

    Space Complexity: O(1)

    Why It Works?
    Because:
    - Each state depends only on previous two states
    - Overlapping subproblems form Fibonacci pattern
    - Constant space iterative optimization
