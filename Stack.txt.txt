1. Valid Parentheses

    Explanation: Given a string containing only '(', ')', '{', '}', '[' and ']', determine if the input string is valid. A string is valid if brackets are closed in the correct order and properly nested.

    Input: s = "()[]{}"

    Output: True

    ==================================================

    BRUTE-FORCE

    Idea: Repeatedly remove valid pairs like (), {}, [] from the string until no changes are possible.

    Steps:
    1. Check if the string contains any valid pair
    2. Remove all occurrences of valid pairs
    3. Repeat until no more removals are possible
    4. If final string is empty, return True else False

    Time Complexity: O(n²)

    Space Complexity: O(n)

    Why It Won't Work Efficiently?
    Because:
    - Repeated string scanning is expensive
    - Multiple passes over same characters
    - Inefficient for long strings

    ==================================================

    OPTIMAL

    Idea:
    Use a stack to store opening brackets. When a closing bracket comes, check if it matches the last opening bracket.

    Steps:
    1. Create an empty stack
    2. Traverse each character in string
    3. Push opening brackets into stack
    4. For closing brackets, check top of stack for match
    5. If mismatch or stack empty, return False
    6. At end, stack should be empty for valid string

    Python Code:

    class Solution:
        def isValid(self, s):

            stack = []

            mapping = {
                ')': '(',
                '}': '{',
                ']': '['
            }

            for char in s:

                if char in mapping:
                    if not stack or stack[-1] != mapping[char]:
                        return False
                    stack.pop()

                else:
                    stack.append(char)

            return len(stack) == 0

    Time Complexity: O(n)

    Space Complexity: O(n)

    Why It Works?
    Because:
    - Stack maintains correct nesting order
    - Last opened bracket is checked first
    - Ensures proper matching of pairs
