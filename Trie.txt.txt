1. Implement Trie (Prefix Tree)

    Explanation: A Trie (Prefix Tree) is a data structure used to store strings efficiently. It allows fast insertion, searching, and prefix checking of words by storing characters in a tree-like structure.

    Input: operations = ["insert", "search", "startsWith"], words = ["apple", "app"], query = "app"

    Output: True (for search), True (for startsWith)

    ==================================================

    BRUTE-FORCE

    Idea: Store all words in a list and perform linear search for insert, search, and prefix matching.

    Steps:
    1. Store words in an array
    2. For search, scan all words and compare strings
    3. For prefix check, manually compare substring of each word

    Time Complexity: O(n * m)

    Space Complexity: O(n)

    Why It Won't Work Efficiently?
    Because:
    - Searching requires scanning all words
    - Prefix checking is slow
    - Repeated comparisons increase time cost

    ==================================================

    OPTIMAL

    Idea:
    Use a tree-like structure where each node represents a character. Words share common prefixes, reducing repeated storage and lookup time.

    Steps:
    1. Create a root node representing empty character
    2. For insert, add characters node by node
    3. For search, traverse character path and check end flag
    4. For prefix check, traverse path without needing end flag

    Python Code:

    class TrieNode:
        def __init__(self):
            self.children = {}
            self.end_of_word = False

    class Trie:

        def __init__(self):
            self.root = TrieNode()

        def insert(self, word):

            node = self.root

            for ch in word:
                if ch not in node.children:
                    node.children[ch] = TrieNode()
                node = node.children[ch]

            node.end_of_word = True

        def search(self, word):

            node = self.root

            for ch in word:
                if ch not in node.children:
                    return False
                node = node.children[ch]

            return node.end_of_word

        def startsWith(self, prefix):

            node = self.root

            for ch in prefix:
                if ch not in node.children:
                    return False
                node = node.children[ch]

            return True

    Time Complexity: O(m)

    Space Complexity: O(n * m)

    Why It Works?
    Because:
    - Common prefixes are shared
    - No repeated full string comparisons
    - Fast traversal using character nodes
