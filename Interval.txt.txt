1. Merge Intervals

    Explanation: Given an array of intervals where intervals[i] = [start, end], merge all overlapping intervals and return an array of non-overlapping intervals covering all input intervals.

    Input: intervals = [[1,3],[2,6],[8,10],[15,18]]

    Output: [[1,6],[8,10],[15,18]]

    ==================================================

    BRUTE-FORCE

    Idea: Compare each interval with every other interval and merge overlapping ones repeatedly until no more merges are possible.

    Steps:
    1. Take each interval one by one
    2. Compare it with all other intervals
    3. If overlap found, merge them into one interval
    4. Repeat process until no changes occur

    Time Complexity: O(n²)

    Space Complexity: O(n)

    Why It Won't Work Efficiently?
    Because:
    - Multiple repeated comparisons
    - Reprocessing same intervals again and again
    - Inefficient for large inputs

    ==================================================

    OPTIMAL

    Idea:
    First sort intervals by start time, then iterate once and merge overlapping intervals on the go.

    Steps:
    1. Sort intervals based on starting value
    2. Initialize result list with first interval
    3. Traverse remaining intervals one by one
    4. If overlap occurs, merge with last interval in result
    5. Otherwise, add new interval to result

    Python Code:

    class Solution:
        def merge(self, intervals):

            intervals.sort(key=lambda x: x[0])

            merged = [intervals[0]]

            for start, end in intervals[1:]:

                last_end = merged[-1][1]

                if start <= last_end:
                    merged[-1][1] = max(last_end, end)

                else:
                    merged.append([start, end])

            return merged

    Time Complexity: O(n log n)

    Space Complexity: O(n)

    Why It Works?
    Because:
    - Sorting arranges intervals in order
    - Only one pass is needed after sorting
    - Overlaps are handled greedily
