✅1. Move Zeroes (Two Pointers)

    Explanation: Move all zeros in the array to the end while keeping the relative order of non-zero elements the same.

    Input: [0, 1, 0, 3, 12]

    Output: [1, 3, 12, 0, 0]

    Clarifying Questions For Interviewer:
    1. Should we modify the array in-place or return a new array?
    2. Can the array contain negative numbers?
    3. Is maintaining relative order of non-zero elements required?
    4. What should be done if there are no zeros?
    5. What is the expected time complexity?

    ==================================================

    BRUTE-FORCE

    Idea: Collect all non-zero elements and then append zeros at the end.

    Steps:
    1. Create a new list for non-zero elements
    2. Count number of zeros in original array
    3. Append zeros at the end

    Python Code:

    class Solution:
        def moveZeroes(self, nums):

            temp = []

            for num in nums:
                if num != 0:
                    temp.append(num)

            zeros = len(nums) - len(temp)

            for i in range(zeros):
                temp.append(0)

            for i in range(len(nums)):
                nums[i] = temp[i]

    Time Complexity: O(n)
    Space Complexity: O(n)

    Why It Won't Work Efficiently?
    Because:
    - Uses extra array space
    - Not in-place
    - Less optimal memory usage

    ==================================================

    OPTIMAL

    Idea:
    Use two pointers to place non-zero elements at the correct position and fill remaining with zeros.

    Steps:
    1. Maintain a pointer for placing non-zero elements
    2. Traverse the array and swap non-zero elements forward
    3. Fill remaining positions with zero

    Python Code:

    class Solution:
        def moveZeroes(self, nums):

            pos = 0

            for i in range(len(nums)):
                if nums[i] != 0:
                    nums[pos], nums[i] = nums[i], nums[pos]
                    pos += 1

    Time Complexity: O(n)
    Space Complexity: O(1)

    Why It Works?
    Because:
    - Moves all non-zero elements in one pass
    - Maintains relative order
    - Uses in-place swapping

✅2. Remove Duplicates from Sorted Array (Two Pointers)

    Explanation: Remove duplicates from a sorted array in-place such that each element appears only once, and return the new length.

    Input: [1, 1, 2]

    Output: 2 (modified array: [1, 2, _])

    Clarifying Questions For Interviewer:
    1. Should the array be modified in-place?
    2. Can we use extra space or must it be O(1)?
    3. Is the array always sorted?
    4. What should be returned: length or modified array?
    5. Are negative numbers allowed?

    ==================================================

    BRUTE-FORCE

    Idea: Use a set to store unique elements and overwrite array.

    Steps:
    1. Create a set to store unique elements
    2. Iterate through array and add elements to set
    3. Overwrite original array with sorted set values

    Python Code:

    class Solution:
        def removeDuplicates(self, nums):

            unique = set()

            for num in nums:
                unique.add(num)

            i = 0
            for val in sorted(unique):
                nums[i] = val
                i += 1

            return len(unique)

    Time Complexity: O(n log n)
    Space Complexity: O(n)

    Why It Won't Work Efficiently?
    Because:
    - Uses extra space
    - Sorting adds extra overhead
    - Does not fully utilize sorted property

    ==================================================

    OPTIMAL

    Idea:
    Use two pointers to overwrite duplicates by tracking unique elements in sorted array.

    Steps:
    1. Use one pointer for unique position
    2. Traverse array with second pointer
    3. Copy only new unique values forward

    Python Code:

    class Solution:
        def removeDuplicates(self, nums):

            if not nums:
                return 0

            slow = 0

            for fast in range(1, len(nums)):
                if nums[fast] != nums[slow]:
                    slow += 1
                    nums[slow] = nums[fast]

            return slow + 1

    Time Complexity: O(n)
    Space Complexity: O(1)

    Why It Works?
    Because:
    - Takes advantage of sorted array
    - Only keeps unique elements in-place
    - Uses constant extra space

✅3. Best Time to Buy and Sell Stock (Greedy / One Pass)

    Explanation: You are given an array where each element represents stock price on a day. You need to find the maximum profit by buying once and selling once.

    Input: [7, 1, 5, 3, 6, 4]

    Output: 5

    Clarifying Questions For Interviewer:
    1. Can we buy and sell multiple times or only once?
    2. Is selling on the same day allowed?
    3. Can prices be negative or zero?
    4. What should be returned if no profit is possible?
    5. Is the array always non-empty?

    ==================================================

    BRUTE-FORCE

    Idea: Try every pair of buy and sell days and calculate maximum profit.

    Steps:
    1. Pick each day as buy day
    2. Check all future days as sell days
    3. Track maximum profit

    Python Code:

    class Solution:
        def maxProfit(self, prices):

            max_profit = 0

            for i in range(len(prices)):
                for j in range(i + 1, len(prices)):

                    profit = prices[j] - prices[i]
                    max_profit = max(max_profit, profit)

            return max_profit

    Time Complexity: O(n^2)
    Space Complexity: O(1)

    Why It Won't Work Efficiently?
    Because:
    - Too many nested comparisons
    - Recomputes same differences repeatedly
    - Not suitable for large input sizes

    ==================================================

    OPTIMAL

    Idea:
    Track the minimum price seen so far and calculate maximum profit at each step.

    Steps:
    1. Initialize min_price as infinity
    2. Traverse array once
    3. Update min_price and max_profit dynamically

    Python Code:

    class Solution:
        def maxProfit(self, prices):

            min_price = float('inf')
            max_profit = 0

            for price in prices:
                if price < min_price:
                    min_price = price
                else:
                    max_profit = max(max_profit, price - min_price)

            return max_profit

    Time Complexity: O(n)
    Space Complexity: O(1)

    Why It Works?
    Because:
    - Keeps track of lowest buy price
    - Computes best sell profit in one pass
    - Avoids unnecessary comparisons

✅4. Rotate Array (Reversal Algorithm / Array Manipulation)

    Explanation: Rotate an array to the right by k steps. Elements shifted beyond the last position reappear at the beginning.

    Input: nums = [1,2,3,4,5,6,7], k = 3

    Output: [5,6,7,1,2,3,4]

    Clarifying Questions For Interviewer:
    1. Should rotation be to the left or right?
    2. Can k be greater than array length?
    3. Should we modify the array in-place?
    4. Can we use extra space?
    5. What should be returned: array or void?

    ==================================================

    BRUTE-FORCE

    Idea: Rotate the array one step at a time, k times.

    Steps:
    1. Repeat k times
    2. Store last element
    3. Shift all elements right by one
    4. Place last element at first position

    Python Code:

    class Solution:
        def rotate(self, nums, k):

            n = len(nums)
            k = k % n

            for _ in range(k):
                last = nums[-1]

                for i in range(n - 1, 0, -1):
                    nums[i] = nums[i - 1]

                nums[0] = last

    Time Complexity: O(n * k)
    Space Complexity: O(1)

    Why It Won't Work Efficiently?
    Because:
    - Repeated shifting is expensive
    - Too slow for large k
    - Inefficient for large arrays

    ==================================================

    OPTIMAL

    Idea:
    Use reversal technique: reverse whole array, then reverse parts.

    Steps:
    1. Reverse entire array
    2. Reverse first k elements
    3. Reverse remaining elements

    Python Code:

    class Solution:
        def rotate(self, nums, k):

            n = len(nums)
            k = k % n

            def reverse(l, r):
                while l < r:
                    nums[l], nums[r] = nums[r], nums[l]
                    l += 1
                    r -= 1

            reverse(0, n - 1)
            reverse(0, k - 1)
            reverse(k, n - 1)

    Time Complexity: O(n)
    Space Complexity: O(1)

    Why It Works?
    Because:
    - Uses in-place reversal logic
    - Efficiently reorders elements in 3 passes
    - Avoids repeated shifting

❌5. Plus One (Array / Simulation)

    Explanation: You are given a non-empty array of digits representing a non-negative integer. Increment the integer by one and return the resulting array.

    Input: [1, 2, 3]

    Output: [1, 2, 4]

    Clarifying Questions For Interviewer:
    1. Can the number contain leading zeros?
    2. What should be done if all digits are 9?
    3. Should we modify the array in-place or return a new one?
    4. Can the input be very large?
    5. Is the array always non-empty?

    ==================================================

    BRUTE-FORCE

    Idea: Convert array to number, add one, then convert back to array.

    Steps:
    1. Convert digits into a single integer
    2. Add 1 to the number
    3. Convert result back to array of digits

    Python Code:

    class Solution:
        def plusOne(self, digits):

            num = 0

            for d in digits:
                num = num * 10 + d

            num += 1

            return [int(x) for x in str(num)]

    Time Complexity: O(n)
    Space Complexity: O(n)

    Why It Won't Work Efficiently?
    Because:
    - Risk of integer overflow in other languages
    - Extra conversion overhead
    - Not truly in-place solution

    ==================================================

    OPTIMAL

    Idea:
    Simulate addition from right to left with carry handling.

    Steps:
    1. Start from last digit
    2. Add 1 and handle carry
    3. If carry remains, add new digit at front

    Python Code:

    class Solution:
        def plusOne(self, digits):

            n = len(digits)

            for i in range(n - 1, -1, -1):

                if digits[i] < 9:
                    digits[i] += 1
                    return digits

                digits[i] = 0

            return [1] + digits

    Time Complexity: O(n)
    Space Complexity: O(1)

    Why It Works?
    Because:
    - Handles carry efficiently
    - Only modifies necessary digits
    - Avoids full number conversion
