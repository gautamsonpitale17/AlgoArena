1. Search in Rotated Sorted Array

    Explanation: Given a rotated sorted array and a target value, return the index of the target if it exists, otherwise return -1. The array was originally sorted in ascending order but rotated at an unknown pivot.

    Input: nums = [4,5,6,7,0,1,2], target = 0

    Output: 4

    ==================================================

    BRUTE-FORCE

    Idea: Check every element one by one to find the target.

    Steps:
    1. Traverse the entire array
    2. Compare each element with target
    3. Return index if match found
    4. If not found, return -1

    Time Complexity: O(n)

    Space Complexity: O(1)

    Why It Won't Work Efficiently?
    Because:
    - Does not use sorted property
    - Linear scan for every search
    - Inefficient for large arrays

    ==================================================

    OPTIMAL

    Idea:
    Use modified binary search. At every step, one half of the array will always be sorted. Use that to decide where to move.

    Steps:
    1. Set left = 0 and right = end of array
    2. Find mid element
    3. Check if left half is sorted or right half is sorted
    4. Decide if target lies in sorted half
    5. Move pointers accordingly

    Python Code:

    class Solution:
        def search(self, nums, target):

            left = 0
            right = len(nums) - 1

            while left <= right:

                mid = (left + right) // 2

                if nums[mid] == target:
                    return mid

                # left half is sorted
                if nums[left] <= nums[mid]:

                    if nums[left] <= target < nums[mid]:
                        right = mid - 1
                    else:
                        left = mid + 1

                # right half is sorted
                else:

                    if nums[mid] < target <= nums[right]:
                        left = mid + 1
                    else:
                        right = mid - 1

            return -1

    Time Complexity: O(log n)

    Space Complexity: O(1)

    Why It Works?
    Because:
    - One half of array is always sorted
    - Binary search reduces search space each step
    - Efficient use of rotation property
