1. Two Sum

    Explanation: Given an array of numbers and a target, find two numbers that add up to the target and return their indices.

    Input: nums = [2,7,11,15], target = 9

    Output: [0,1]

    ==================================================

    BRUTE-FORCE

    Idea: Try every possible pair and check if their sum equals the target.

    Steps:
    1. Pick one element
    2. Compare it with every other element
    3. If sum equals target, return both indices

    JavaScript Code:
    
    class Solution {
        twoSum(nums, target) {

            for (let i = 0; i < nums.length; i++) {
                for (let j = i + 1; j < nums.length; j++) {
                    if (nums[i] + nums[j] === target) {
                        return [i, j];
                    }
                }
            }

        }
    }

    Time Complexity: O(n^2)

    Space Complexity: O(1)

    Why It Won't Work Efficiently?
    Because:
    - It checks every possible pair
    - It becomes very slow for large arrays
    - Too many repeated comparisons

    ==================================================

    OPTIMAL

    Idea:
    Use a hash map to store numbers and their indices so we can find the required complement in constant time.

    Steps:
    1. Create a map to store visited numbers
    2. For each number, compute complement (target - number)
    3. If complement exists in map, return result

    JavaScript Code:

    class Solution {
        twoSum(nums, target) {

            const map = new Map();

            for (let i = 0; i < nums.length; i++) {
                let complement = target - nums[i];

                if (map.has(complement)) {
                    return [map.get(complement), i];
                }

                map.set(nums[i], i);
            }

        }
    }

    Time Complexity: O(n)

    Space Complexity: O(n)

    Why It Works?
    Because:
    - Each element is processed only once
    - Hash map allows instant lookup
    - Avoids checking all pairs
