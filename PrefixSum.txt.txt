1. Subarray Sum Equals K

    Explanation: Given an integer array and an integer k, return the total number of continuous subarrays whose sum equals k.

    Input: nums = [1,1,1], k = 2

    Output: 2

    ==================================================

    BRUTE-FORCE

    Idea: Try every possible subarray and calculate its sum, then check if it equals k.

    Steps:
    1. Start from each index as a starting point
    2. Expand subarray to the right one element at a time
    3. Calculate sum for each subarray
    4. Count if sum equals k

    Time Complexity: O(n²)

    Space Complexity: O(1)

    Why It Won't Work Efficiently?
    Because:
    - Recomputing sums for every subarray
    - Nested iteration over array
    - Inefficient for large inputs

    ==================================================

    OPTIMAL

    Idea:
    Use prefix sum with a hashmap to store frequency of prefix sums. If (current_sum - k) exists, it means a valid subarray exists.

    Steps:
    1. Maintain running prefix sum
    2. Store frequency of prefix sums in a hashmap
    3. For each element, check if (prefix_sum - k) exists
    4. Add result based on frequency count

    Python Code:

    class Solution:
        def subarraySum(self, nums, k):

            prefix_map = {0: 1}
            prefix_sum = 0
            count = 0

            for num in nums:

                prefix_sum += num

                if (prefix_sum - k) in prefix_map:
                    count += prefix_map[prefix_sum - k]

                prefix_map[prefix_sum] = prefix_map.get(prefix_sum, 0) + 1

            return count

    Time Complexity: O(n)

    Space Complexity: O(n)

    Why It Works?
    Because:
    - Prefix sum converts subarray sum into difference problem
    - Hashmap stores previous sums efficiently
    - Avoids recomputation of all subarrays
