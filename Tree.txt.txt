1. Level Order Traversal of Binary Tree

    Explanation: Given a binary tree, traverse all nodes level by level from left to right. This means visiting all nodes at depth 0 first, then depth 1, and so on.

    Input: root = [3,9,20,null,null,15,7]

    Output: [[3],[9,20],[15,7]]

    ==================================================

    BRUTE-FORCE

    Idea: Visit each level separately by finding height of tree and printing nodes at each level using recursion.

    Steps:
    1. Find height of the binary tree
    2. For each level from 1 to height
    3. Collect nodes present at that level using recursive traversal

    Time Complexity: O(n²)

    Space Complexity: O(n)

    Why It Won't Work Efficiently?
    Because:
    - Each level is traversed again and again
    - Repeated scanning of nodes increases time cost
    - Inefficient for large trees

    ==================================================

    OPTIMAL

    Idea:
    Use a queue to process nodes level by level. Push root first, then process nodes in FIFO order while adding their children.

    Steps:
    1. Initialize a queue with root node
    2. While queue is not empty, process current level
    3. Remove nodes from queue and store their values
    4. Add left and right children to queue

    Python Code:

    from collections import deque

    class Solution:
        def levelOrder(self, root):

            if not root:
                return []

            queue = deque([root])
            result = []

            while queue:

                level = []
                size = len(queue)

                for _ in range(size):

                    node = queue.popleft()
                    level.append(node.val)

                    if node.left:
                        queue.append(node.left)

                    if node.right:
                        queue.append(node.right)

                result.append(level)

            return result

    Time Complexity: O(n)

    Space Complexity: O(n)

    Why It Works?
    Because:
    - Each node is visited exactly once
    - Queue ensures level-by-level processing
    - Efficient BFS traversal of tree
