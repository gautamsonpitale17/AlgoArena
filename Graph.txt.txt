1. Number of Islands

    Explanation: Given a 2D grid map of '1's (land) and '0's (water), return the number of islands. An island is surrounded by water and is formed by connecting adjacent lands horizontally or vertically.

    Input: grid = [
        ["1","1","0","0"],
        ["1","0","0","1"],
        ["0","0","1","1"]
    ]

    Output: 3

    ==================================================

    BRUTE-FORCE

    Idea: For every cell that is land, check its connected land cells using repeated scanning, and mark visited cells by rechecking the whole grid multiple times.

    Steps:
    1. Traverse each cell in the grid
    2. When land is found, try to find all connected land using repeated full-grid scans
    3. Mark visited cells manually using extra tracking
    4. Count each discovered connected component as one island

    Time Complexity: O((n*m)²)

    Space Complexity: O(n*m)

    Why It Won't Work Efficiently?
    Because:
    - Repeated scanning of entire grid for connectivity
    - Very inefficient marking and revisiting of cells
    - High time cost for large grids

    ==================================================

    OPTIMAL

    Idea:
    Use DFS or BFS to explore and mark all connected land cells whenever an unvisited land cell is found.

    Steps:
    1. Traverse each cell in the grid
    2. If cell is '1', start DFS to mark all connected land
    3. Mark visited cells as '0' during traversal
    4. Increase island count for each DFS call

    Python Code:

    class Solution:
        def numIslands(self, grid):

            if not grid:
                return 0

            rows = len(grid)
            cols = len(grid[0])
            islands = 0

            def dfs(r, c):

                if r < 0 or c < 0 or r >= rows or c >= cols:
                    return

                if grid[r][c] == "0":
                    return

                grid[r][c] = "0"

                dfs(r+1, c)
                dfs(r-1, c)
                dfs(r, c+1)
                dfs(r, c-1)

            for r in range(rows):
                for c in range(cols):

                    if grid[r][c] == "1":
                        islands += 1
                        dfs(r, c)

            return islands

    Time Complexity: O(n * m)

    Space Complexity: O(n * m)

    Why It Works?
    Because:
    - Each cell is visited only once
    - DFS efficiently marks entire connected component
    - No repeated scanning of grid
