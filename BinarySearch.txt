✅1. Binary Search (Binary Search)

    Explanation: Given a sorted array and a target value, find the index of the target. Return -1 if the target does not exist.

    Input: nums = [-1,0,3,5,9,12], target = 9

    Output: 4

    Clarifying Questions For Interviewer:
    1. Is the array always sorted in ascending order?
    2. Can the array contain duplicate values?
    3. What should be returned if the target is not found?
    4. Can the array be empty?
    5. Are negative numbers allowed?

    ==================================================

    BRUTE-FORCE

    Idea: Traverse the array linearly and check every element.

    Steps:
    1. Start from the first element
    2. Compare each element with target
    3. Return index if found, otherwise return -1

    Python Code:

    class Solution:
        def search(self, nums, target):

            for i in range(len(nums)):
                if nums[i] == target:
                    return i

            return -1

    Time Complexity: O(n)
    Space Complexity: O(1)

    Why It Won't Work Efficiently?
    Because:
    - Checks elements one by one
    - Does not utilize sorted property
    - Slow for large arrays

    ==================================================

    OPTIMAL

    Idea:
    Use the sorted property to repeatedly eliminate half of the search space.

    Steps:
    1. Initialize left and right pointers
    2. Find middle element
    3. Compare middle with target
    4. Search left half or right half accordingly

    Python Code:

    class Solution:
        def search(self, nums, target):

            left = 0
            right = len(nums) - 1

            while left <= right: 

                mid = left + (right - left) // 2

                if nums[mid] == target:
                    return mid

                elif nums[mid] < target:
                    left = mid + 1

                else:
                    right = mid - 1

            return -1

    Time Complexity: O(log n)
    Space Complexity: O(1)

    Why It Works?
    Because:
    - Eliminates half of the search space each step
    - Uses sorted array efficiently
    - Achieves logarithmic time complexity

✅2. Search Insert Position (Binary Search)

    Explanation: Given a sorted array and a target value, return the index if the target is found. If not, return the index where it should be inserted to maintain sorted order.

    Input: nums = [1,3,5,6], target = 5

    Output: 2

    Clarifying Questions For Interviewer:
    1. Is the array always sorted in ascending order?
    2. Can the array contain duplicate values?
    3. Can the target be smaller than all elements?
    4. Can the target be greater than all elements?
    5. Should the insertion maintain sorted order?

    ==================================================

    BRUTE-FORCE

    Idea: Traverse the array and find the first position where the target can be placed.

    Steps:
    1. Iterate through the array
    2. If current element is greater than or equal to target, return its index
    3. If no such element exists, return array length

    Python Code:

    class Solution:
        def searchInsert(self, nums, target):

            for i in range(len(nums)):
                if nums[i] >= target:
                    return i

            return len(nums)

    Time Complexity: O(n)
    Space Complexity: O(1)

    Why It Won't Work Efficiently?
    Because:
    - Scans elements one by one
    - Does not utilize sorted property
    - Slow for large arrays

    ==================================================

    OPTIMAL

    Idea:
    Use binary search to find the target or its correct insertion position.

    Steps:
    1. Initialize left and right pointers
    2. Check middle element
    3. Move to left or right half accordingly
    4. Return left pointer as insertion position

    Python Code:

    class Solution:
        def searchInsert(self, nums, target):

            left = 0
            right = len(nums) - 1

            while left <= right:

                mid = left + (right - left) // 2

                if nums[mid] == target:
                    return mid

                elif nums[mid] < target:
                    left = mid + 1

                else:
                    right = mid - 1

            return left

    Time Complexity: O(log n)
    Space Complexity: O(1)

    Why It Works?
    Because:
    - Uses binary search on sorted array
    - Finds exact position efficiently
    - Left pointer naturally becomes insertion index

✅3. First Bad Version (Binary Search)

    Explanation: You are given versions from 1 to n. Once a version becomes bad, all versions after it are also bad. Find the first bad version using the provided isBadVersion() API.

    Input: n = 5, firstBadVersion = 4

    Output: 4

    Clarifying Questions For Interviewer:
    1. Is it guaranteed that at least one bad version exists?
    2. Can n be very large?
    3. Is isBadVersion() the only API available?
    4. Should we minimize API calls?
    5. Are versions numbered from 1?

    ==================================================

    BRUTE-FORCE

    Idea: Check each version one by one until a bad version is found.

    Steps:
    1. Start from version 1
    2. Call isBadVersion() for each version
    3. Return the first bad version found

    Python Code:

    class Solution:
        def firstBadVersion(self, n):

            for version in range(1, n + 1):

                if isBadVersion(version):
                    return version

    Time Complexity: O(n)
    Space Complexity: O(1)

    Why It Won't Work Efficiently?
    Because:
    - Checks versions sequentially
    - Too many API calls
    - Slow for very large n

    ==================================================

    OPTIMAL

    Idea:
    Use binary search to locate the boundary between good and bad versions.

    Steps:
    1. Set left = 1 and right = n
    2. Check middle version
    3. If middle is bad, search left half
    4. Otherwise search right half
    5. Return first bad version

    Python Code:

    class Solution:
        def firstBadVersion(self, n):

            left = 1
            right = n

            while left < right:
 
                mid = left + (right - left) // 2

                if isBadVersion(mid):
                    right = mid
                else:
                    left = mid + 1

            return left

    Time Complexity: O(log n)
    Space Complexity: O(1)

    Why It Works?
    Because:
    - Eliminates half of the versions each step
    - Efficiently finds the first bad version
    - Minimizes API calls

✅4. Guess Number Higher or Lower (Binary Search)

    Explanation: You need to guess a number between 1 and n. The API guess(num) returns:
    - -1 if your guess is higher than the picked number
    - 1 if your guess is lower than the picked number
    - 0 if your guess is correct

    Find the picked number.

    Input: n = 10, pick = 6

    Output: 6

    Clarifying Questions For Interviewer:
    1. Is the picked number always between 1 and n?
    2. Can n be very large?
    3. Is guess(num) the only API available?
    4. Should we minimize the number of guesses?
    5. Is there always exactly one correct answer?

    ==================================================

    BRUTE-FORCE

    Idea: Try every number from 1 to n until the correct number is found.

    Steps:
    1. Start from 1
    2. Call guess() for each number
    3. Return when guess() returns 0

    Python Code:

    class Solution:
        def guessNumber(self, n):

            for num in range(1, n + 1):

                if guess(num) == 0:
                    return num

    Time Complexity: O(n)
    Space Complexity: O(1)

    Why It Won't Work Efficiently?
    Because:
    - May require checking every number
    - Too many API calls
    - Slow for large n

    ==================================================

    OPTIMAL

    Idea:
    Use binary search to eliminate half of the search space after each guess.

    Steps:
    1. Set left = 1 and right = n
    2. Guess the middle number
    3. Adjust search range based on API response
    4. Repeat until correct number is found

    Python Code:

    class Solution:
        def guessNumber(self, n):

            left = 1
            right = n

            while left <= right:

                mid = left + (right - left) // 2

                result = guess(mid)

                if result == 0:
                    return mid

                elif result == 1:
                    left = mid + 1

                else:
                    right = mid - 1

    Time Complexity: O(log n)
    Space Complexity: O(1)

    Why It Works?
    Because:
    - Removes half of the remaining numbers each step
    - Uses API feedback efficiently
    - Minimizes the number of guesses

✅5. Find Smallest Letter Greater Than Target (Binary Search)

    Explanation: Given a sorted array of letters and a target letter, find the smallest letter that is greater than the target. The letters wrap around, meaning if no letter is greater, return the first letter.

    Input: letters = ["c","f","j"], target = "a"

    Output: "c"

    Clarifying Questions For Interviewer:
    1. Is the letters array always sorted?
    2. Can the array contain duplicate letters?
    3. Should the search be case-sensitive?
    4. Is wrap-around behavior always required?
    5. Is the array guaranteed to be non-empty?

    ==================================================

    BRUTE-FORCE

    Idea: Traverse the array and return the first letter greater than target.

    Steps:
    1. Iterate through the letters array
    2. Check if current letter is greater than target
    3. Return the first matching letter
    4. If none found, return the first letter

    Python Code:

    class Solution:
        def nextGreatestLetter(self, letters, target):

            for ch in letters:

                if ch > target:
                    return ch

            return letters[0]

    Time Complexity: O(n)
    Space Complexity: O(1)

    Why It Won't Work Efficiently?
    Because:
    - Checks letters one by one
    - Does not use sorted property
    - Slower for large arrays

    ==================================================

    OPTIMAL

    Idea:
    Use binary search to find the first letter greater than target.

    Steps:
    1. Initialize left and right pointers
    2. Search for the first letter greater than target
    3. Store potential answer when found
    4. Return answer or first letter for wrap-around

    Python Code:

    class Solution:
        def nextGreatestLetter(self, letters, target):

            left = 0
            right = len(letters) - 1

            while left <= right:

                mid = left + (right - left) // 2

                if letters[mid] > target:
                    right = mid - 1
                else:
                    left = mid + 1

            return letters[left % len(letters)]

    Time Complexity: O(log n)
    Space Complexity: O(1)

    Why It Works?
    Because:
    - Uses binary search on sorted letters
    - Finds the first valid greater letter efficiently
    - Modulo handles wrap-around automatically
