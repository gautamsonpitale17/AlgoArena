1. Kth Largest Element in an Array

    Explanation: Given an integer array and an integer k, return the kth largest element in the array. The kth largest element is the element that would be at position k if the array was sorted in descending order.

    Input: nums = [3,2,1,5,6,4], k = 2

    Output: 5

    ==================================================

    BRUTE-FORCE

    Idea: Sort the array in descending order and directly pick the kth element.

    Steps:
    1. Sort the array in descending order
    2. Access the element at index k-1
    3. Return that element

    Time Complexity: O(n log n)

    Space Complexity: O(1) or O(n) depending on sorting

    Why It Won't Work Efficiently?
    Because:
    - Sorting the entire array is unnecessary for a single element
    - Extra computation even though only kth element is needed
    - Not optimal for large datasets

    ==================================================

    OPTIMAL

    Idea:
    Use a min-heap of size k. Keep only k largest elements in the heap. The smallest among them will be the kth largest overall.

    Steps:
    1. Create a min-heap
    2. Iterate through array elements
    3. Push element into heap
    4. If heap size exceeds k, remove smallest element
    5. Top of heap is kth largest element

    Python Code:

    import heapq

    class Solution:
        def findKthLargest(self, nums, k):

            heap = []

            for num in nums:

                heapq.heappush(heap, num)

                if len(heap) > k:
                    heapq.heappop(heap)

            return heap[0]

    Time Complexity: O(n log k)

    Space Complexity: O(k)

    Why It Works?
    Because:
    - Heap keeps only k largest elements
    - Smaller elements are removed automatically
    - Efficient compared to full sorting
